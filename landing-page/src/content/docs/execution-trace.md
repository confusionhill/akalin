# Vertical Execution Trace & Token Metrics

Debugging multi-turn agentic workflows requires visibility into every decision step between the user and the LLM.

---

## 1. Vertical Execution Timeline

Akalin visualizes multi-turn lifecycle execution steps:
1. `User Input` — The initial request payload.
2. `AI Tool Call` — Function call name and generated parameters.
3. `Tool Output` — Mocked or live return payload.
4. `AI Final Answer` — Final completion output.

---

## 2. Granular Token Audit

Every step records exact token consumption metrics:
- **Prompt Tokens (`in`)**: Input token counts passed to the provider.
- **Completion Tokens (`out`)**: Output tokens generated by the model.
- **Total Tokens**: Consolidated step consumption for cost tracking.
